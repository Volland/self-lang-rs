4. Speicherung in Ihrem Browser

Der Playground speichert den Code, den Sie gerade bearbeiten, als Entwurf im lokalen Speicher Ihres Browsers („Local Storage“, Schlüssel self-playground-draft), damit er beim nächsten Aufruf nicht verloren ist. Dieser Entwurf verbleibt auf Ihrem Gerät und wird weder an mich noch an Dritte übertragen. Sie können ihn jederzeit über die Einstellungen Ihres Browsers löschen.

Die Speicherung ist unbedingt erforderlich, um die von Ihnen ausdrücklich gewünschte Editor-Funktion bereitzustellen (§ 25 Abs. 2 Nr. 2 TDDDG); eine Einwilligung ist daher nicht erforderlich.

5. Ihre Programme bleiben auf Ihrem Gerät

Self World läuft als WebAssembly vollständig in Ihrem Browser. Code, den Sie im Playground, auf der Seite „Self → JavaScript“ oder im Desktop eingeben, wird ausschließlich lokal ausgeführt bzw. übersetzt und nicht an einen Server gesendet. Das gilt auch für Web-Apps, die Sie dort erzeugen und herunterladen.

Mit der Funktion „Share link“ wird Ihr Code in den Teil der Adresse nach dem Zeichen „#“ geschrieben. Dieser Teil wird von Browsern nicht an den Server übertragen; der Code wird nur dann weitergegeben, wenn Sie den Link selbst mit anderen teilen.
